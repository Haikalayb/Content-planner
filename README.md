# Content Planner Kreator

Sistem perencanaan konten TikTok/Reels: jadwal posting, status produksi, deadline, dan rekap pemasukan endorsement.
Dibuat dengan HTML, CSS, dan JavaScript murni (tanpa framework).

## Struktur
- index.html     : struktur halaman
- css/style.css  : tampilan
- js/script.js   : logika (CRUD, filter, deadline, rekap, localStorage)

## Cara membuka di WebStorm
1. File > Open, pilih folder content-planner-webstorm.
2. Klik kanan index.html > Open in > Browser (atau klik ikon browser di pojok kanan atas editor).
